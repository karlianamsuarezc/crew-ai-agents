# 🤖 AI Agents Experiments with CrewAI & Google Gemini

Repositorio dedicado a la exploración, desarrollo y aplicación práctica de flujos de trabajo con agentes autónomos utilizando **CrewAI** impulsados por **Google Gemini** (`langchain-google-genai`).

## 📁 Estructura del Proyecto
- `notebooks/`: Contiene los Jupyter Notebooks prácticos de lecciones y pruebas de concepto.
- `config/`: Archivos de configuración YAML que definen los roles, metas (*backstories*) de los agentes y las tareas específicas.
- `helper.py`: Utilidades para la gestión de entornos de ejecución.

## 🚀 Tecnologías y Stack
- **Python 3.10+**
- **CrewAI & CrewAI Tools**
- **Google Gemini API (via LangChain)**
- **Pydantic** (para estructuración y validación de outputs)
